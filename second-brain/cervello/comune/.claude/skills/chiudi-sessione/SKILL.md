# Chiudi sessione

Ripercorri la conversazione di questa sessione e fai, mostrando prima le modifiche:

1. **Memoria**
   - `MEMORY.md` generale: voce in cima con data di oggi, cosa è stato fatto, decisioni, cosa resta aperto.
   - Per ogni cliente/progetto toccato: stessa cosa nel suo `MEMORY.md`.
   - Aggiorna le liste "In sospeso" (spunta ciò che è chiuso).
2. **Mappa**: se sono nate cartelle, clienti, skill o regole nuove, aggiorna `AGENTS.md`
   (e l'`AGENTS.md` dell'ala). Tienila snella: solo puntatori.
3. **Biblioteca**: se in sessione è uscito un documento "buono" e riusabile, proponi di ricavarne
   un modello in `reference/` e aggiorna `reference/README.md`.
4. **Procedure**: se una stessa richiesta è stata fatta 2+ volte, proponi una nuova skill.
5. **Inbox**: segnala i file in `inbox/` ancora da smistare.
6. **Igiene**: se `MEMORY.md` supera ~150 righe, sposta le voci più vecchie in `archivio/memory-AAAA.md`.
7. Se la memoria Honcho è attiva, salva come conclusioni le preferenze nuove emerse.

Chiudi con un riepilogo di 3 righe di ciò che hai aggiornato.
