# Biblioteca (reference)

Modelli ed esempi "buoni" da cui l'agente parte quando produce un documento.
Regola: un file = un tipo di documento. Aggiungi qui sotto ogni nuovo modello.

| File | Cosa è | Ricavato da |
|---|---|---|
| `struttura-offerta.md` | Struttura di un'offerta/preventivo professionale | Modello di partenza (da sostituire con una tua offerta reale) |

**Come aggiungere un modello da un PDF:** metti il PDF in `inbox/` e chiedi:
"Analizza `inbox/<file>.pdf` e ricavane la struttura in `reference/<tipo>.md`: sezioni, tono, lunghezza,
elementi fissi e variabili. Non copiare dati del cliente." Poi aggiorna questa tabella.
